# Blocklight - A blazing fast mcfunction microcompiler

Blocklight is an in-progress Minecraft mcfunction microcompiler focused on solving the issues everyone else ignores. It is designed to stay out of your way. See [RELEASE_README.md](RELEASE_README.md) for more information on the planned design. Check back in a few weeks to see what's been created!
